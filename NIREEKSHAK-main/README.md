## 📌 Overview

**NIREEKSHAK** is an AI-powered software platform designed to analyze **MPLADS (Members of Parliament Local Area Development Scheme)** project data and identify unusual patterns that may require further human review.

Instead of automatically declaring a project fraudulent, NIREEKSHAK combines multiple analytical signals to generate an **explainable risk score** and provides supporting evidence to help authorities prioritize projects for investigation.
